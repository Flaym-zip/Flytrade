# Choix de refonte

La maquette fournie par Claude apporte une palette et une hierarchie visuelle.
Elle propose plusieurs pistes et n'est pas branchee a l'API. Le frontend conserve
le code fonctionnel de l'archive utilisateur, avec un habillage adapte :

- bleu pour hausse, indigo pour stable, violet pour baisse ;
- vert/rouge reserves a gain/perte financiers ;
- ambre pour hypotheses, cotations et confirmations de remplacement ;
- distinction atelier qui apprend / copie live gelee ;
- etapes numerotees, reglages avances repliees, prochaine action contextuelle ;
- confirmations explicites et visite qui montre sans executer.

Aucune police ni bibliotheque tierce issue de la maquette n'est livree.
Le Wiki conserve ses 21 chapitres techniques et ajoute huit entrees debutants.
Chaque ancien chapitre recoit un resume simple avant les formules.

Les remises a zero ne detruisent pas les corpus. Les archives sont telechargeables
mais leur restoration arbitraire n'est pas automatisee. Les sessions sont suivies
par identifiant et le test deja ouvert reste signale lors d'une nouvelle experience.
